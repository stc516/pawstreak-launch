# PawStreak Beta Bug Intake Template

Use this for texts, DMs, emails, or internal notes.

## Quick triage labels

P0 — stop inviting:

- Cannot sign up/sign in.
- Dog/profile/memory/photo does not persist.
- Adventure cannot finish.
- Private data visible across accounts.
- Account deletion fails.
- App unusable on iPhone Safari.

P1 — fix before expanding:

- Instagram share missing image.
- Push enable/disable broken.
- Primary CTA hidden/clipped.
- User does not know what to do next.
- Production shows fake/demo data.

P2 — improve later:

- Visual polish.
- Copy improvement.
- More places/content.
- Nice-to-have animation.
- Non-core feature idea.

## Daily bug review

At the end of each beta day, answer:

1. Any P0 today?
2. Any repeated P1 from more than one tester?
3. Did anyone fail to complete the core loop?
4. Did anyone lose a photo/memory?
5. Did anyone come back for a second adventure?
6. What is the one fix that would most improve tomorrow?
