# Weekly social performance review

Run on Sunday after recording every published URL. Do not fill missing metrics
with zero; use `UNAVAILABLE` so access problems are not mistaken for poor
performance.

## Post log

| Published URL | Content ID | Brand | Theme | Format | Reach | Impressions | Saves | Comments | Shares | Link clicks | Profile actions |
| --- | --- | --- | --- | --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| | | | | | | | | | | | |

## Calculations

- Engagement rate by reach = `(saves + comments + shares) / reach`.
- Click rate by impressions = `link clicks / impressions`.
- Conversation signal = substantive comments and DMs, reviewed manually.
- Place-intent signal = tracked clicks to a specific Places listing.
- Beta-intent signal = valid beta inquiries, counted only when enrollment is
  genuinely available.

## Review questions

1. Which post created the most saves or qualified clicks, not merely views?
2. Which opening line and asset held attention best?
3. What factual questions or listing corrections appeared?
4. Did any CTA promise something the product cannot yet deliver?
5. Which theme has at least three comparable posts? Avoid declaring a winner
   from one post.
6. What single variable should change next week: topic, asset, opening line,
   format, CTA, or time?

## Decision record

```text
Week ending:
Available data:
Best-supported observation:
What remains uncertain:
One change for next week:
Owner approval:
```

Keep product delays, account-access delays, and publishing delays separate.
Low reach caused by a disconnected channel is not a content-performance result.
