# Bailey & Omi repeatable book system

Each gate has one owner decision and one saved artifact. The official creative bible outranks this checklist.

| Gate | Required artifact | Pass condition |
|---|---|---|
| Idea | One-page concept card | Real-world grounding, fresh relationship structure, clear visual engine |
| Story outline | 10–14 beat outline | Beginning/middle/end; humor; emotional turn; neither dog flattened into a role |
| Manuscript | Versioned text manuscript | Read-aloud rhythm, age fit, no preachy explanation, word count target met |
| Page plan | 24/32-page map | Every turn earns a reveal; front/back matter reserved; no orphaned text |
| Illustration plan | Shot list + thumbnail contact sheet | Scale, setting, time, action, and page-turn intent stated |
| Character consistency | Bailey/Omi model-sheet check | markings, eyes, collars, ear shapes, relative size, personality all pass |
| Illustration production | Approved finals folder | warm watercolor/colored-pencil language; print-resolution masters; no generic substitutes |
| Book assembly | Print PDF + fixed-layout EPUB + covers | filenames/version recorded; fonts/images embedded; links and end matter final |
| Print validation | Preflight report + rendered contact sheet | trim, bleed, spine, margins, page order, resolution, color, QR all pass |
| Kindle validation | EPUBCheck/preview notes | no errors; readable on representative devices; cover and navigation correct |
| Website | Series update + book page | canonical, schema, social image, accessibility, real-dog connection, safe availability state |
| KDP | Submission record | metadata, rights, categories, keywords, prices, previews, and editions recorded |
| Launch | Approved copy/calendar + asset manifest | URLs verified, no false availability, truthful review request, channel assets ready |

## Folder and version rule

Use `BXX_title/stage/` with versions such as `B02_manuscript_v03_2026-10-06.md`. Final publishing filenames include format and production facts, for example `B02_Title_Paperback_Interior_8.5x8.5_32pp_v1.pdf`. Never overwrite a submitted master; supersede it with a new version and record why.

## Three fast reviews

1. **Story review:** Does each dog want something? Who is surprised? What changes between them?
2. **Visual review:** Put every spread in a contact sheet and check dog identity, collar color, scale, direction, setting continuity, and text-safe space.
3. **Release review:** Validate files, website, Amazon metadata, links, and launch claims against the exact submitted version.

## Reusable release checklist

- [ ] Creative bible checked; relationship pattern differs from prior books.
- [ ] Real-world inspiration and permissions documented.
- [ ] Manuscript read aloud to at least two listeners; edits incorporated.
- [ ] Page turns and total print page count locked before final art.
- [ ] Bailey/Omi consistency checked on every spread.
- [ ] Production PDF and EPUB validated independently.
- [ ] QR resolves to the permanent HTTPS book page.
- [ ] Website works with JavaScript disabled except optional signup enhancement.
- [ ] Amazon buttons stay non-clickable until their edition pages are live.
- [ ] Launch copy uses verified URLs and never requests a positive/incentivized review.
