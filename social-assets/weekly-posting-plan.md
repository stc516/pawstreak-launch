## Editorial and release rules

1. Use only manifest-listed screenshots and screen recordings captured from PawStreak itself, approved real Bailey/Meiomi photos, or verified real locations. Never swap in stock imagery, fabricated UI or customer stories.
2. Preserve the visible `DEMO` label on preview captures; do not treat demo data as live user accomplishments.
3. Use **no more than five hashtags**. Mention specific access rules, amenities, hours or availability only with a current verified source.
4. Never imply direct Instagram posting from the app; describe the actual device share/export flow.
5. Keep all concepts **Pending approval / Unpublished** until the owner authorizes publishing.
6. When live browser access is unavailable, reuse verified captures. Avoid making duplicate generated screenshots or representing archived captures as new footage.

For new content, append one date to the CSV and its matching packet/story entries. Check that every referenced file is present in `assets.json` and the next seven local calendar dates are covered before requesting approval.
