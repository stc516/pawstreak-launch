# Current, reviewed app captures only

Historical screenshots, Stories, and videos outside this directory are reference archives, not current product assets. They are excluded from Content Studio and the application bundle.

Only add an asset here after checking its actual screen against the current app, confirming that photos and numbers are authentic, and obtaining owner approval. Add its path to `social-assets/assets.json` with `reviewStatus: "approved-current"`. Record the captured commit, date, and approval in the social operations source registry. Do not use fabricated maps, seeded activity counts, or demo dog photos as real user activity.

`social:capture` produces demo reference captures; it does not approve assets. Its demo label must stay visible. Do not schedule or publish from this directory without separate authorization.
