## Channel map

- Instagram feed: cover, woodland pair, stairs illustration; crop only from copies.
- Instagram Stories: portrait photos or cover centered on cream; keep text outside faces/title.
- TikTok/Reels: simple vertical sequence using real-dog photo → approved illustration → cover; no synthetic dog animation.
- Facebook/personal sharing: real-dogs photo plus Book 1 URL.
- Email: cover plus one real-dogs photo, both linked to the Book 1 page.
- Website: repository WebP files above.
- Amazon announcements: cover only until the corresponding Amazon detail page is verified live.
